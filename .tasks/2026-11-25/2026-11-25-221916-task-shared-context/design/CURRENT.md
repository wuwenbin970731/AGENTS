## 文件职责

- `TASK.md`：目标、范围、验收标准、当前状态、下一步。
- `CONTEXT.md`：本任务及其后代共同使用的稳定约定，包括术语定义、固定参数、计算口径、共同前提与适用范围。
- design / decision / evidence：详细设计、决策原因、验证证据，经 Context Map 按需读取。
- 当前进展、执行日志、未确认想法不作为已生效共同约定；不要求每个 Task 额外维护 GLOSSARY 或 ADR。

## 创建与内容

所有 Task 支持该机制，有第一条实际约定时才创建 CONTEXT.md。已有 Task 不批量补建空文件，也不自动将历史讨论提炼为已确认约定。
文件只保留有内容的章节：术语与定义、固定参数与口径、共同前提与范围、对继承约定的显式例外。
必要时附简短依据或资源引用，详细论证通过 Context Map 加载。
例如“基线模型的版本”“一轮实验的步骤”“指标聚合方式”适合写入；单次运行进度不适合。

## 继承与作用范围

- 本 Task 的约定默认作用于自身及全部后代。
- 子 Task 可增加本地约定，作用于自身及其后代。
- 与祖先约定冲突必须显式声明局部例外、范围及原因，不采用隐式就近覆盖。
- 父任务定义统一分辨率时，子任务的实验例外不影响兄弟；若改变父任务验收条件，则回到父任务处理变更。
- 兄弟任务不互相继承；跨任务树共享使用显式依赖契约。

## 加载与渐进披露

现有 Runtime 按 Context Map 读取资源，选中子任务不自动读取祖先正文；本方案需要新增明确、受限的共享上下文加载授权。
发现 Task 仍只读取 Meta。选中或恢复 Task 后，加载祖先链及自身实际存在的 CONTEXT.md；不顺带读取祖先 TASK.md、设计或证据。
为 taskctl 增加专门入口：定位祖先链文件，按根到当前任务顺序列出来源、大小、版本指纹，在预算内读取并标注所属 Task。
超预算明确报告，不静默截断或遗漏祖先约定。CONTEXT.md 保持短小，大资料留在 Context Map；不自动展开文件中的链接。
具体命令接口、预算策略及安全边界实现须在编码前形成可审查设计。

## 更新、一致性与并发

- 用户确认定义、参数或共同前提后，由 Agent 更新所属 Task 的 CONTEXT.md。
- 未确认想法保留在讨论或设计中；子任务需要调整上层约定时明确提出上层变更，不悄悄修改父文件。
- 恢复、开始执行、提交验收前检查已加载上下文有无变化；变化后重新读取并检查影响。
- 使用文件内容指纹检测变化，无须逐条约定建立复杂版本系统。
- 写入必须检测并发冲突；具体与 Task revision、资源写入协议的衔接待实现设计确定。

## 验收场景

1. 单独进入深层 Subtask，能获得全部适用祖先约定及本地约定，并识别来源。
2. 父级更新后，子 Task 下次工作能发现变化并重新检查影响。
3. 局部例外可追溯且不影响兄弟；未显式解决的冲突不会静默覆盖。
4. 没有 CONTEXT.md 的旧 Task 继续正常使用；创建时不生成无内容文件。
5. 发现阶段只读 Meta；加载不越界展开其他任务正文或资源链接。
6. 超预算和并发冲突明确反馈，不截断、不覆盖。
7. 受影响测试和仓库规定检查通过，模板与自用副本保持一致。

## 实现设计（2026-11-25，编码前）

- 保持 schema 5 兼容，不新增必填 Meta、不默认生成 CONTEXT.md，不改普通发现命令。
- 增加 context shared-list/read/check/write。list 返回按根到当前排序的来源、存在状态、大小、SHA-256 及整链 fingerprint；计算指纹会流式读文件字节，但不披露正文。缺失文件也纳入整链指纹，检测后续创建/删除。
- read 以 JSON 返回 fingerprint 与来源标注的各份正文，不进行语义合并。默认总正文预算 32 KiB，支持 max-bytes/max-tokens；输出前完整检查总预算、实际读取大小及整链指纹，失败不输出部分正文。预算不含 JSON 包装开销。
- check 使用调用方保存的 expect-fingerprint 对比当前整链；变化以 exit 3 反馈。无需另建持久缓存或强制 session 绑定。
- write 仅写显式指定 Task 的本地文件，要求 expect-sha256（首次用 missing）和 expect-revision；复用 Task 短时锁，锁内重新检查内容指纹和 revision，原子替换资源后递增入口 revision。拒绝空白内容。两个文件不是一个事务；中断后以资源内容指纹为变化依据，不能只依赖 revision。
- 祖先链通过精确 parent_task ID 连接，检测缺失、重复 ID、循环，超过 100 节点明确失败而不截断。文件必须在所属 Task 目录内，不接受 CONTEXT.md 符号链接或指向其他 Task 的路径；不递归展开文内链接。
- 约定冲突属于自然语言语义，由 Skill 要求 Agent 显式解决；CLI 保留原文和来源，不宣称自动理解或消解冲突。
- 更新 Skill、协议、schema 说明、TASK_WORKFLOW、TASK_TEMPLATE、README 与 PROJECT_AGENTS 的任务加载提示，模板同步自用副本。全局规则源不作扩展，以免引入系统级同步。
- 测试覆盖深层继承、兄弟隔离、缺失与创建删除检测、父更新、总预算、符号链接、异常祖先链、版本冲突和锁冲突；执行完整仓库检查及临时项目 CLI 验证。
