# Task 共享上下文约定

## 术语与定义

- 共享约定：用户确认的稳定术语、参数、单位、计算口径、共同前提与适用范围；不包含执行进度、日志或未确认提案。
- 约定所属 Task：保存该 CONTEXT.md 的任务；约定默认作用于自身及全部后代。
- 局部例外：明确列出祖先约定来源、例外原因及适用范围的本地约定；不影响兄弟 Task。

## 共同前提与范围

- 每个 Task 都支持共享约定，但仅有实际内容时创建 CONTEXT.md；不批量生成空文件或自动提取历史共识。
- 继承使用祖先链引用，不复制父文件，不静默覆盖冲突；跨任务树共享仍使用显式依赖。
- 共享加载仅覆盖祖先链与自身 CONTEXT.md，不展开祖先 TASK.md、其他资源或文件中的链接。
- 本 Task 实施范围为本仓库 Runtime、协议、模板及测试；不自动更新下游项目；提交与推送按用户明确授权执行。
