# 独立会话命名验证

用户已授权验证 Orca 与 Codex 的命名接入，不修改生产编排逻辑。

1. 使用实际安装版本指南和协议 schema。
2. 在现有 Orca workspace 创建明确标记的测试 terminal/Codex 会话，只提交“回复验证标记、不使用工具、不修改文件”的短任务。
3. 从该 terminal 的运行时证据取得真实 Codex session ID，不靠标题或创建时间猜测。
4. 用受支持的 app-server 接口仅修改该测试会话的持久化名称，核对 thread/read/list；再用独立连接复核持久化与恢复。
5. 如元数据接入不通，再在该空闲测试 terminal 验证 /rename，不操控任何业务 worker。
6. 保存脱敏证据与能力边界，保留或安全关闭本次测试会话，不删除其他会话。

不读取无关对话，不改 Codex 全局配置，不更换模型，不启动业务任务。完整恢复测试须区分“读到持久化名称”“按 ID resume 成功”“实际 resume UI 展示”三个证据层级。
