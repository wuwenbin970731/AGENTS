编号与创建：父锁内分配下一个层级键

SUBTASK_KEY_PATTERN = re.compile(
    r"^S[1-9][0-9]*(?:\.[1-9][0-9]*)*$"
)

def next_child_key(parent, children):
    parent_key = parent.get("subtask_key")
    if parent_key:
        pattern = re.compile(
            rf"^{re.escape(parent_key)}\.([1-9][0-9]*)$"
        )
        prefix = f"{parent_key}."
    elif not parent.get("parent_task"):
        pattern = re.compile(r"^S([1-9][0-9]*)$")
        prefix = "S"
    else:
        raise TaskCtlError(
            "legacy nested parent requires --subtask-key"
        )

    used = []
    for _, meta in children:
        match = pattern.fullmatch(str(meta.get("subtask_key") or ""))
        if match:
            used.append(int(match.group(1)))
    return f"{prefix}{max(used, default=0) + 1}"

创建子 Task 时，代码先锁住父 Task，再读取兄弟节点。它会拒绝重复编号和错误前缀。

def compact_tree_meta(meta, *, child_count, tree_depth):
    return {
        "id": meta.get("id"),
        "subtask_key": meta.get("subtask_key"),
        "title": meta.get("title"),
        "status": meta.get("status"),
        "summary": meta.get("summary"),

返回值不包含 Task 正文、设计文档、迭代和证据。调用方必须再次选择节点，才能进入 L1。
